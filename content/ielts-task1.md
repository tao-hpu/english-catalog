## 一、Task 1 评分与基本认知

### 评分四维度(每项 25%)

| 维度 | 缩写 | 考查 |
|------|------|------|
| **任务完成** | TA(Task Achievement) | 抓住主特征 + 数据准确 + 写够 150 字 |
| **连贯衔接** | CC(Coherence & Cohesion) | 段落清晰 + 连接词得当 |
| **词汇** | LR(Lexical Resource) | 同义替换 + 描述变化的动词丰富 |
| **语法** | GR(Grammatical Range) | 时态正确(过去/现在/将来)+ 复杂句 |

### ⚠️ Task 1 八大铁律

1. **不少于 150 字**(少了直接扣分)
2. **不要写自己观点 / 原因**("This is because..."→ ❌ Task 1 不能写)
3. **必须分段**(开头 / 概述 / 主体 1 / 主体 2 → 至少 4 段)
4. **必须有 overview**(总体趋势,**最重要的得分点!**)
5. **数据要准确**(数字 / 单位 / 年份不能错)
6. **时态正确**(过去图 → 过去时;预测图 → 将来时)
7. **不要逐点抄数据**(选典型,做对比)
8. **复杂句至少 2-3 处**(不要全是简单句)

### 📊 时间分配建议

| 步骤 | 时间 |
|------|------|
| 审题 + 列纲 | 3 min |
| 写作 | 15 min |
| 检查 | 2 min |

## 二、万能 4 段式结构

```
┌─────────────────────────────────────────┐
│ Para 1:Paraphrase 题目(改写)         │ 1 句
│ Para 2:Overview 总体趋势 ⭐ 关键        │ 2-3 句
│ Para 3:Body 1 主体描述(主要数据)      │ 3-4 句
│ Para 4:Body 2 主体描述(对比 / 次要)   │ 3-4 句
└─────────────────────────────────────────┘

总字数:160-180 字最佳
```

### Para 1:Paraphrase 题目

**核心:** 不要照抄题目,**换词** + **改结构**!

#### 改写三招:

| 招数 | 例 |
|------|-----|
| 换名词 | chart → graph / figure / diagram |
| 换动词 | shows → illustrates / depicts / presents / provides information about |
| 换名词化 | "people who own a car" → "car ownership" |

#### 模板:

> The [chart / graph / table / map] **illustrates / shows / compares / provides information about** [改写的题目内容] **between [年] and [年] / in [地点]**.

**例:**
> 题目:The graph below shows the number of cars sold in three countries from 2000 to 2020.
>
> 改写:The line graph **illustrates car sales in three countries** **over a 20-year period from 2000 to 2020**.

### Para 2:Overview ⭐⭐⭐(决定上 6 还是上 7)

**Overview = 不写数字,只写"宏观趋势 / 最显著特征"**

#### Overview 公式:

```
Overall, it is clear that [整体趋势 1].
In addition, [整体趋势 2 / 对比].
```

#### 不同图型的 Overview 写什么?

| 图型 | Overview 内容 |
|------|------------|
| 折线图 | 上升 / 下降 / 波动的总体趋势 + 最高最低 |
| 柱状图 | 哪个最高、哪个最低、有什么对比 |
| 饼图 | 谁占最大份额、最小份额 |
| 表格 | 总体格局、最显著差异 |
| 地图 | 总体变化(更现代 / 更绿化 / 更复杂) |
| 流程图 | 步骤总数、起点终点、是否循环 |

⚠️ **Overview 不能有数字!** 数字都放主体段。

### Para 3-4:Body 描述

**两段切分原则:**

| 切分逻辑 | 例 |
|---------|-----|
| 时间分(图横跨多年) | 前半段 / 后半段 |
| 项目分 | 项目 A / 项目 B |
| 趋势分 | 上升组 / 下降组 |
| 比例分 | 大比例 / 小比例 |

## 三、题型 1:折线图(Line Chart)

### 1️⃣ 折线图重点 = 描述变化趋势

### 2️⃣ 必备词汇

#### 上升类

| 强度 | 动词 | 名词 |
|------|------|------|
| 慢 | rose / increased / climbed / grew | a rise / an increase / growth |
| 快 | jumped / soared / surged / rocketed | a surge / a jump |

#### 下降类

| 强度 | 动词 | 名词 |
|------|------|------|
| 慢 | fell / decreased / declined / dropped | a fall / a decrease / a drop |
| 快 | plunged / plummeted / collapsed | a plunge / a collapse |

#### 平稳类

| 表达 | 动词 / 名词 |
|------|----------|
| 稳定 | remained stable / steady / constant / unchanged |
| 波动 | fluctuated / oscillated |

#### 峰值低谷

| 表达 | 例 |
|------|-----|
| 顶峰 | reached a peak of [数字] / peaked at [数字] |
| 低谷 | hit a low of [数字] / bottomed out at [数字] |

### 3️⃣ 修饰副词(描述程度)

| 程度 | 副词 |
|------|------|
| 显著 | significantly / dramatically / sharply / considerably |
| 轻微 | slightly / marginally / gradually |
| 稳定 | steadily / consistently |

### 4️⃣ 描述变化的两种句型 ⭐

```
句型 A:动词 + 副词
The number of cars rose sharply.

句型 B:there be + 形容词 + 名词 + in
There was a sharp rise in the number of cars.
```

📌 **建议交替使用,展现语法多样性。**

### 5️⃣ 折线图完整范文(180 字)

```
题目:The graph shows electricity consumption in 3 countries from 2000 to 2020.

The line graph illustrates the consumption of electricity in three countries
— China, India and the USA — over a two-decade period from 2000 to 2020.

Overall, it is evident that all three countries experienced an upward trend
in electricity use, with China showing by far the most dramatic increase.
The USA, in contrast, remained relatively stable throughout the period.

In 2000, China consumed approximately 1,500 TWh, which was lower than the
USA's figure of around 3,500 TWh. However, China's consumption rose sharply
over the next 20 years, surpassing the USA in around 2010 and reaching
roughly 7,500 TWh by 2020 — a fivefold increase.

India also saw considerable growth, climbing from about 400 TWh in 2000
to approximately 1,500 TWh in 2020, although the rate of growth was less
pronounced than that of China. The USA's consumption fluctuated mildly
between 3,500 and 4,200 TWh, ending the period at much the same level
as it had started.
```

## 四、题型 2:柱状图(Bar Chart)

### 1️⃣ 柱状图重点 = 对比

### 2️⃣ 比较句型

#### 大比小

```
A is significantly / considerably / much higher than B.
A is over twice as high as B.
A is three times the figure for B.
A exceeded B by [数字].
```

#### 小比大

```
B is far lower than A.
B accounted for only half of A.
B was less than a third of A.
```

#### 相等

```
A and B were almost identical / roughly the same.
A was on a par with B.
```

#### 排序

```
A had the highest figure, followed by B, then C.
The most popular was A, while the least popular was C.
```

### 3️⃣ 柱状图分类

| 类型 | 描述重点 |
|------|---------|
| **静态柱状图**(无时间) | 项目对比 + 排序 |
| **动态柱状图**(有时间) | 同折线图,描述变化 + 项目对比 |

### 4️⃣ 柱状图范文模板

```
题目:Bar chart shows internet usage by age groups in 4 countries.

The bar chart compares internet usage rates across four age groups in
[国家 A], [B], [C] and [D].

Overall, internet usage decreased with age in all four countries, with
the youngest age group (16-24) showing near-universal access, while the
oldest group (65+) had significantly lower rates.

In the 16-24 age bracket, all four countries reported usage rates above
95%, with [国家] leading at [数字]%. The figures for the 25-44 group were
also high, ranging from [X]% to [Y]%, suggesting that the digital divide
in this group is minimal.

A more pronounced difference emerged in the 45-64 group, where rates
varied from [X]% to [Y]%. The starkest contrast appeared in the 65+
category: while [国家 A] maintained a relatively high rate of [X]%,
[国家 D] dropped to just [Y]%, indicating substantial generational
disparities in some countries.
```

## 五、题型 3:饼图(Pie Chart)

### 1️⃣ 饼图重点 = 比例

### 2️⃣ 比例描述句型

```
A accounted for X% of the total.
A made up X% / constituted X%.
X% of the total was attributed to A.
A represented X% of all [people / cases / spending].
```

### 3️⃣ 比例形容词

| 比例 | 表达 |
|------|------|
| 占多数 | the majority / over half / a substantial proportion |
| 占少数 | the minority / a small fraction / a tiny percentage |
| 一半 | half / 50% / equal halves |
| 四分之一 | a quarter / one in four |
| 三分之一 | a third / one in three |
| 五分之一 | a fifth / 20% |

### 4️⃣ 多个饼图的对比

题目常见:**两年的饼图对比 → 写"哪些上升、哪些下降、哪些不变"**

```
While [类别 A]'s share rose from X% to Y%, [类别 B]'s proportion fell from
P% to Q%. [类别 C], by contrast, remained largely unchanged at around X%.
```

### 5️⃣ 饼图范文模板

```
The pie charts illustrate the breakdown of household spending in [国家]
in 2000 and 2020.

Overall, the most striking change is the dramatic shift away from food
spending toward housing and entertainment, while spending on essentials
like clothing remained relatively stable.

In 2000, the largest share of household spending went to food, accounting
for around 40% of the total. Housing came in second at approximately 25%,
followed by clothing (15%), transport (10%), and entertainment, which
made up just 10%.

By 2020, the picture had changed significantly. Housing had become the
largest expense, climbing to 35%, while food's share had dropped sharply
to 25%. Spending on entertainment more than doubled, reaching 22%, which
suggests a meaningful change in lifestyle priorities. Transport and
clothing showed only minor changes.
```

## 六、题型 4:表格(Table)

### 1️⃣ 表格 = 包含多组数据,本质是"折线 + 柱状的混合"

### 2️⃣ 处理表格的三步法

```
1. 找最大值和最小值(必写)
2. 找最显著对比(必写)
3. 选 2-3 个典型数据,不要全抄
```

### 3️⃣ 表格选择性描述策略

```
Body 1:写 "winners"(数据最高的项目)
Body 2:写 "losers"(数据最低的项目 / 反趋势项目)

或者:
Body 1:写最显著的国家 / 项目 / 类别
Body 2:写其余的总体规律
```

### 4️⃣ 表格范文模板

```
The table provides data on [改写题目] in [年份] across [国家 / 类别].

Overall, [国家 A] consistently outperformed the others in [指标],
while [国家 B] lagged behind in most categories. A notable pattern is
that [显著趋势 1].

Looking at the highest figures, [国家 A] led in [类别 1] with [数字],
followed by [国家 C] at [数字]. In addition, [国家 A] also dominated
[类别 2], accounting for over half of the total at [数字]%.

By contrast, [国家 B] reported the lowest figures in nearly every
category, with particularly low values in [类别]. Interestingly,
[国家 D] showed mixed results — while it ranked high in [类别 X],
it was among the lowest in [类别 Y].
```

## 七、题型 5:地图(Map)

### 1️⃣ 地图重点 = 描述"变化"

雅思地图题 90% 是**对比同一地点不同时期的两幅图**(过去 vs 现在 / 现在 vs 计划)。

### 2️⃣ 必备词汇

#### 出现 / 建造

| 表达 | 用法 |
|------|------|
| was built / constructed / erected | A factory was built. |
| appeared / emerged | A park appeared in the south. |
| was added / introduced | A new road was added. |

#### 拆除 / 消失

| 表达 | 用法 |
|------|------|
| was demolished / pulled down / torn down | The old factory was demolished. |
| was removed / cleared | The trees were cleared. |
| disappeared / vanished | The forest disappeared. |

#### 改造 / 转变(关键!)

| 表达 | 例 |
|------|-----|
| **A was converted / transformed into B** | The factory was converted into a museum. |
| **A was replaced by B** | The forest was replaced by a car park. |
| **A made way for B** | The old houses made way for apartments. |
| **A gave way to B** | The trees gave way to buildings. |

#### 扩展 / 缩减

| 表达 | 例 |
|------|-----|
| was expanded / enlarged | The school was expanded. |
| was extended | The road was extended. |
| was reduced / shrunk | The garden was reduced in size. |

### 3️⃣ 方位介词必备 ⭐

```
in the north / south / east / west of [the area]
in the northeast / northwest / southeast / southwest
on the left / right side
in the centre / middle
adjacent to / next to / beside [X]
opposite [X]
across from [X]
to the north of [X]
along [the river / road]
surrounded by [X]
```

📌 **常用句型:**
> In the northern part of the area, ...
> A new building was constructed **adjacent to** the school.
> The park is located **to the south of** the river.

### 4️⃣ 地图题时态选择

| 题目情境 | 时态 |
|---------|------|
| 过去 vs 现在 | 过去时(was built) |
| 现在 vs 计划 | 现在 + 将来(will be built) |
| 两个过去时间点 | 都用过去时 |

### 5️⃣ 地图范文模板

```
The two maps illustrate the changes that took place in [地名] between
[年] and [年].

Overall, the area underwent significant transformation, evolving from
a [原貌,如 rural / industrial] zone into a more [现貌,如 commercial /
residential / green] one. The most notable changes were [概述变化].

In [年 1], the [northern / central] part of the area was dominated
by [建筑/景观], while [其他区域] consisted mainly of [景观]. There
was [其他特征].

By [年 2], the area had been substantially redeveloped. The [建筑]
in the north had been demolished and replaced by [新建筑]. To the
south, [新建筑] was constructed in place of [旧的]. In addition,
[其他变化], suggesting a clear shift toward [总体方向].
```

### 6️⃣ 地图题加分技巧

| 技巧 | 例 |
|------|-----|
| 用过去完成时显层次 | "By 2020, the factory **had been demolished**." |
| 用被动语态突出客观 | "A new road **was constructed** to the east." |
| 用 "while / whereas" 对比 | "While the school **was expanded**, the park **was reduced** in size." |
| 用 "in addition to / along with" 添加 | "Along with these changes, a parking area **was introduced**." |

## 八、题型 6:流程图(Process)

### 1️⃣ 流程图 = 描述步骤,**永远用一般现在时被动语态**

### 2️⃣ 必备词汇

#### 顺序词(连接步骤)

| 阶段 | 词 |
|------|-----|
| 起始 | First / Firstly / To begin with / Initially / At the first stage |
| 中间 | Then / Next / After that / Subsequently / Following this |
| 同时 | Meanwhile / At the same time / Simultaneously |
| 最后 | Finally / In the final stage / Lastly |

#### 流程动词(常用被动)

| 动词 | 含义 |
|------|------|
| be collected / gathered | 被收集 |
| be processed / treated | 被处理 |
| be filtered / purified | 被过滤 / 净化 |
| be heated / cooled | 被加热 / 冷却 |
| be mixed / blended | 被混合 |
| be packaged / packed | 被包装 |
| be transported / delivered | 被运输 |
| be stored | 被储存 |

### 3️⃣ 流程图分段策略

```
Para 1:改写题目 + 总体说"this process consists of X stages"
Para 2:Overview(总步骤数 + 起点 + 终点 + 是否循环)
Para 3:前半部分流程
Para 4:后半部分流程
```

### 4️⃣ 流程图范文模板

```
The diagram illustrates the [process of producing X / how Y works],
which consists of [总步骤数] main stages.

Overall, the process begins with [起点] and ends with [终点]. The first
half is dominated by [关键过程类型,如 raw material processing], while
the second half focuses on [如 final packaging and distribution].

In the initial stage, [原料] is collected and transported to [地点].
The material is then [处理 1], after which it is [处理 2]. Following
this, [处理 3].

In the next phase, the [中间产物] is [处理 4]. Once this is complete,
it is [处理 5]. Finally, the finished product is [包装 / 储存 / 运输],
ready for [最终用途].
```

### 5️⃣ 流程图加分句型

| 句型 | 例 |
|------|-----|
| It is at this stage that ... | It is at this stage that the material is purified. |
| Once X has been done, Y can begin. | Once the dough has been mixed, baking can begin. |
| The X is then ready to be Y-ed. | The product is then ready to be shipped. |
| This entire cycle takes approximately ... | This entire cycle takes approximately 24 hours. |

## 九、Task 1 高分词汇与句型

### 🎯 改写题目核心动词(替换 show)

| show 的替换 |
|-----------|
| illustrate / depict / portray |
| present / display / outline |
| provide information about |
| compare(对比图)/ summarise(综合) |
| give an overview of |

### 🎯 描述变化的高分动词

| 上升 | 下降 | 平稳 |
|------|------|------|
| escalate | plummet | level off |
| skyrocket | dwindle | plateau |
| surge | dip | hold steady |

### 🎯 描述程度的高分副词

| 显著 | 轻微 |
|------|------|
| dramatically | slightly |
| sharply | marginally |
| substantially | gradually |
| considerably | modestly |
| significantly | minimally |

### 🎯 连接词(段内 / 段间)

| 类型 | 词 |
|------|-----|
| 添加 | Furthermore / Moreover / In addition |
| 对比 | However / In contrast / On the other hand / Whereas |
| 因果 | As a result / Consequently / Therefore |
| 举例 | For instance / For example / To illustrate |
| 总结 | Overall / In summary / All in all |
| 时间 | Initially / Subsequently / Finally |

### 🎯 数据描述高分句型

```
The figure / number rose from X to Y, an increase of Z%.
There was a significant rise in [指标], climbing from X to Y.
[项目] saw a dramatic increase, more than doubling from X to Y.
The figure for X was [数字], compared to [数字] for Y.
Sales of A exceeded those of B by [数字].
A constituted the largest share, at [数字]%.
A and B made up [总比例]% combined.
```

### 🎯 时态决策

| 图的时间 | 用什么时态 |
|---------|----------|
| 过去某段时间(明确年份) | 一般过去时 |
| 现在的情况(无年份 / 现在数据) | 一般现在时 |
| 未来的预测(forecast / projected) | 一般将来时 / will + 原形 |
| 过去到现在的变化 | 现在完成时(过程)+ 过去时(动作) |
| 流程图(无时间标记) | 一般现在时被动 |
| 地图改造图 | 过去时被动(was built) |
