## 一、核心比喻:5 个层次

```
┌─────────────────────────────────────────────────┐
│                                                 │
│  Level 1:词性     = 演员的"身份证"             │
│             (这个演员是哪一类人?)               │
│                                                 │
│  Level 2:成分     = 演员在剧中演的"角色"        │
│             (这个演员在这场戏里干什么?)         │
│                                                 │
│  Level 3:句型     = "剧本结构"                  │
│             (一场戏的最基本骨架长什么样?)       │
│                                                 │
│  Level 4:句子种类 = "电影的剧情复杂度"          │
│             (单线 / 双线 / 主从 / 主从混搭?)    │
│                                                 │
│  Level 5:语气     = "电影的情绪基调"            │
│             (陈述 / 疑问 / 命令 / 感叹?)        │
│                                                 │
│  Level 6:特殊结构 = "导演的高级手法"            │
│             (倒装 / 强调 / 省略 / 插入...)      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### ⚠️ 中国学生最大的盲点

```
误区:"形容词就是表语"
真相:形容词 ≠ 表语
     - 形容词是"身份"(level 1,词性)
     - 表语是"角色"(level 2,成分)
     - 形容词可以演表语,也可以演定语
     - 表语也不必由形容词演,名词/介词短语/从句都行
```

**示例:**

| 句子 | tall 的身份(词性) | tall 的角色(成分) |
|------|----------------|----------------|
| This tree is **tall**. | 形容词 | **表语** |
| I see a **tall** tree. | 形容词 | **定语** |
| He grew **tall**. | 形容词 | **表语**(系动词 grow 后) |

## 二、Level 1:词性(8 大演员身份)

**词性 = 这个单词天生属于哪一类。** 一辈子不变(基本上)。

### 1️⃣ 八大词类一览

| # | 词类 | 缩写 | 作用 | 例 |
|---|------|------|------|-----|
| 1 | **名词** Noun | n. | 人 / 物 / 概念 | tree, love, freedom |
| 2 | **代词** Pronoun | pron. | 代替名词 | he, she, it, this, who |
| 3 | **动词** Verb | v. | 动作 / 状态 | run, eat, **be**, seem |
| 4 | **形容词** Adjective | adj. | 描述名词特征 | tall, happy, beautiful |
| 5 | **副词** Adverb | adv. | 修饰动 / 形 / 副 / 句 | quickly, very, here |
| 6 | **介词** Preposition | prep. | 表关系 | in, on, at, of |
| 7 | **连词** Conjunction | conj. | 连接词 / 句 | and, but, because |
| 8 | **感叹词** Interjection | interj. | 情绪 | Oh! Wow! Ouch! |

📌 **附加 2 类(扩展词类):**
- **冠词** Article — a, an, the(归入限定词 Determiner)
- **数词** Numeral — one, two, first

### 2️⃣ 同一个词可以"兼职"不同词性

英语词的"身份"会因为用法变化。

| 词 | 名词 | 动词 | 形容词 |
|----|------|------|--------|
| **water** | drink the **water**(水) | **water** the plants(浇水) | — |
| **light** | turn on the **light**(灯) | **light** a candle(点燃) | a **light** color(浅色) |
| **fast** | — | — | a **fast** car(形)/ run **fast**(副) |
| **back** | my **back** hurts(后背) | **back** me up(支持) | the **back** door(后门) |

⚠️ **查词典看词性标记,这才是地道英语的关键。**

### 3️⃣ 关于动词的特殊分类

动词内部还分:

| 子类 | 例 | 作用 |
|------|-----|------|
| **实义动词** | run, eat, write | 表实际动作 |
| **系动词** | be, seem, become, look | 连接主语和表语("等号") |
| **助动词** | do, have, will, can | 帮主动词构成时态 / 疑问 / 否定 |
| **情态动词** | can, may, must, should | 表能力 / 可能 / 义务 |

## 三、Level 2:句子成分(8 大角色)

**成分 = 这个词在当前这句话里"干什么"。** 随句子变,不固定。

### 1️⃣ 八大句子成分一览

| # | 成分 | 中 | 英 | 例(对应词加粗) |
|---|------|----|----|------------|
| 1 | **主语** | 谁 / 什么 | Subject (S) | **The boy** runs. |
| 2 | **谓语** | 做什么 / 是什么 | Predicate / Verb (V) | The boy **runs**. |
| 3 | **宾语** | 动作对象 | Object (O) | I love **English**. |
| 4 | **表语** | 描述主语 | Predicative / SC | She is **a teacher**. |
| 5 | **定语** | 修饰名词 | Attributive / Modifier | a **red** apple |
| 6 | **状语** | 修饰动 / 句 | Adverbial (A) | He runs **fast** / **at home**. |
| 7 | **补语** | 补充说明宾 / 主 | Complement (C) | They made him **captain**. |
| 8 | **同位语** | 同等说明 | Appositive | My brother, **a doctor**, is here. |

### 2️⃣ 每个成分能由哪些"词性 / 短语 / 从句"来演?⭐

这是**最关键的对应表**——成分是角色,但演这个角色的"演员"可以是不同身份。

#### 主语(谁 / 什么)

| 演员 | 例 |
|------|-----|
| 名词 | **Tom** is here. |
| 代词 | **He** is here. |
| 动名词 | **Swimming** is fun. |
| 不定式 | **To learn** is important. |
| 名词性从句 | **What you said** is true. |
| 形式主语 it | **It** is important **to learn**. |

#### 谓语(动作 / 状态)

```
只能由动词来演!
```

可能是:
- 一般动词:He **runs**.
- 助动词 + 动词:He **is running** / **has run** / **will run**.
- 情态动词 + 动词:He **can run**.

#### 宾语(动作的对象)

| 演员 | 例 |
|------|-----|
| 名词 | I love **English**. |
| 代词 | I love **you**. |
| 动名词 | I enjoy **reading**. |
| 不定式 | I want **to leave**. |
| 名词性从句 | I know **that he is busy**. |

#### 表语(描述主语)⭐ 用户最关心的

| 演员 | 例 |
|------|-----|
| 形容词 | She is **happy**. |
| 名词 | She is **a teacher**. |
| 代词 | The book is **mine**. |
| 介词短语 | The meeting is **at 5 PM**. |
| 副词 | The party is **over**. |
| 不定式 | My dream is **to travel the world**. |
| 动名词 | His hobby is **collecting stamps**. |
| 从句 | The problem is **that we have no money**. |

📌 **关键:** 表语**不一定**是形容词!这是中国学生最大盲点。

#### 定语(修饰名词)

| 演员 | 例 |
|------|-----|
| 形容词 | a **beautiful** girl |
| 名词 | a **stone** bridge(石头桥) |
| 代词 | **my** book |
| 数词 | **three** apples |
| 冠词 | **the** book |
| 介词短语 | the book **on the table** |
| 不定式 | something **to drink** |
| 分词 | a **sleeping** baby / a **broken** window |
| 定语从句 | the book **which I read** |

#### 状语(修饰动 / 形 / 副 / 句)

| 演员 | 例 |
|------|-----|
| 副词 | He runs **quickly**. |
| 介词短语 | He runs **in the park**. |
| 名词词组 | He runs **every morning**. |
| 不定式 | He works hard **to support his family**.(目的) |
| 分词 | **Tired**, he sat down.(原因) |
| 状语从句 | He runs **because he's late**. |

#### 补语(补充说明)

分两种:**主语补足语** 和 **宾语补足语**

| 类型 | 演员 | 例 |
|------|------|-----|
| 主语补足语(被动后) | 形 / 名 / 不定式 | He was elected **chairman**. |
| 宾语补足语 | 形 / 名 / 不定式 / 分词 / 原形 | I found him **honest** / made him **cry** / saw him **running** |

#### 同位语(同等说明)

| 演员 | 例 |
|------|-----|
| 名词 | My friend **Tom** is here. |
| 名词短语 | Beijing, **the capital of China**, is huge. |
| 从句 | The fact **that he lied** shocked me. |

### 3️⃣ 演员 × 角色 对应总表 ⭐

```
                              【演员】(词性)
              名词  动词  形容词  副词  介词短语  不定式  动名词  分词  从句
              ─────────────────────────────────────────────────────────
【角色】主语   ✅   ✗    ✗      ✗     ✗        ✅      ✅     ✗    ✅(名词性)
       谓语   ✗   ✅    ✗      ✗     ✗        ✗      ✗     ✗    ✗
       宾语   ✅   ✗    ✗      ✗     ✗        ✅      ✅     ✗    ✅(名词性)
       表语   ✅   ✗    ✅     ✅(限)✅       ✅      ✅     ✗    ✅(名词性)
       定语   ✅   ✗    ✅     ✗     ✅        ✅      ✗     ✅   ✅(定语从句)
       状语   ✗   ✗    ✗      ✅    ✅        ✅      ✗     ✅   ✅(状语从句)
       补语   ✅   ✗    ✅     ✗     ✗        ✅      ✗     ✅   ✗
       同位语 ✅   ✗    ✗      ✗     ✗        ✗      ✗     ✗    ✅(同位语从句)
```

📌 **关键观察:**
- 谓语只能由动词演(唯一不变)
- 名词、不定式、动名词、名词性从句 —— 都能演主 / 宾 / 表
- 形容词、分词、定语从句 —— 都能演定语
- 副词、介词短语、状语从句 —— 都能演状语

## 四、Level 3:基本句型(5 大剧本)

**句型 = 主谓宾表补的搭配模式。** 英语所有句子都是这 5 种基本句型 + 修饰的扩展。

### 五大基本句型一览

| # | 句型 | 类比 | 例 |
|---|------|------|-----|
| 1 | **S + V** | "光杆动作" | The baby cried. |
| 2 | **S + V + O** | "做了什么" | I love English. |
| 3 | **S + V + P** | "是怎样的" | She is happy. |
| 4 | **S + V + IO + DO** | "给谁什么" | I gave him a book. |
| 5 | **S + V + O + C** | "让宾语怎样" | I made him cry. |

### 加 1 个特殊:there be

```
There + be + 主语 + 地点 / 时间
```

> **There is** a book on the table.

📌 详细的句型分析见 [英语句型结构与五大基本句型.md](英语句型结构与五大基本句型.md)。

## 五、Level 4:句子种类按结构分(4 种)

**按"句子里有几个主谓 + 怎么连"分。**

### 1️⃣ 简单句(Simple Sentence)

**一个主谓结构。**

> **The boy reads.**
> **The tall boy reads a book in the library every morning.**(加再多修饰也是简单句)

📌 **判断标志:** 只有**一套主谓**。

### 2️⃣ 并列句(Compound Sentence)

**两个或多个简单句,用并列连词连接。**

```
简单句 1 + 并列连词 + 简单句 2
```

#### 并列连词("FANBOYS"):
| 连词 | 含义 |
|------|------|
| **F**or | 因为 |
| **A**nd | 和 |
| **N**or | 也不 |
| **B**ut | 但是 |
| **O**r | 或者 |
| **Y**et | 然而 |
| **S**o | 所以 |

**例:**
> **I love coffee, but my wife prefers tea.**
> **He worked hard, so he passed the exam.**
> **You can stay here, or you can come with me.**

### 3️⃣ 复合句(Complex Sentence)

**一个主句 + 一个或多个从句。**

```
主句 + 从属连词 + 从句
```

#### 三大从句类型:
- **名词性从句**(主 / 宾 / 表 / 同位)→ that, whether, what...
- **定语从句** → who, which, that...
- **状语从句** → when, because, although...

**例:**
> **I know that you are tired.**(宾语从句)
> **The book which I bought is good.**(定语从句)
> **I went home because it rained.**(状语从句)

📌 详细分析见 [英语三大从句完全指南.md](英语三大从句完全指南.md)。

### 4️⃣ 并列复合句(Compound-Complex Sentence)

**至少 2 个主句 + 至少 1 个从句。**

```
主句 1 + 并列连词 + 主句 2,其中至少一个含从句
```

**例:**
> **I love coffee that has cream**, **but** **my wife prefers tea that is sweet**.
>   主句 1 + 定语从句    并列      主句 2 + 定语从句

### 5️⃣ 4 种结构对比

| 种类 | 主谓数 | 连接方式 | 例 |
|------|--------|---------|-----|
| 简单句 | 1 | — | I am happy. |
| 并列句 | 2+ | 并列连词(FANBOYS) | I am happy **and** I am free. |
| 复合句 | 1 主 + 1+ 从 | 从属连词 | I am happy **because** I am free. |
| 并列复合句 | 2+ 主 + 1+ 从 | 两种都有 | I am happy **and** I dance **whenever** I can. |

## 六、Level 5:句子种类按语气分(4 种)

**按句子"想干什么"分。**

### 1️⃣ 陈述句(Declarative)

**陈述事实 / 观点,以句号结尾。**

> She is a teacher.
> The earth is round.

#### 子类:
- 肯定:She is happy.
- 否定:She is **not** happy.

### 2️⃣ 疑问句(Interrogative)

**提问,以问号结尾。**

#### 子类:

| 类型 | 例 | 答 |
|------|-----|-----|
| **一般疑问句** | Are you tired? | Yes / No |
| **特殊疑问句** | Where do you live? | 具体信息 |
| **选择疑问句** | Tea or coffee? | 二选一 |
| **反义疑问句** | You're tired, aren't you? | 确认 |

📌 详见 [英语句型结构与五大基本句型.md](英语句型结构与五大基本句型.md)#四疑问句构造。

### 3️⃣ 祈使句(Imperative)

**命令 / 请求 / 建议,常省略主语 you。**

> **Open** the door.
> **Don't** be late.
> **Please** sit down.
> **Let's** go.

#### 加强语气:
- Do come in!(请进来啊)→ do + 原形 强调
- Never mind.(没关系)

### 4️⃣ 感叹句(Exclamatory)

**强烈情绪,以感叹号结尾。**

#### 两种模式:

```
What + (a / an) + 形容词 + 名词 + (主谓)!
How + 形容词 / 副词 + (主谓)!
```

> **What** a beautiful day (it is)!
> **What** beautiful flowers (they are)!
> **How** beautiful (the flowers are)!
> **How** quickly time flies!

#### 区分 What 和 How:
- **What** 后面带名词
- **How** 后面带形容词 / 副词

| ✅ | ❌ |
|----|----|
| What a great idea! | How a great idea! |
| How great! | What great! |

## 七、Level 6:特殊结构(7 种"高级戏法")

雅思 7 分以上必备。

### 1️⃣ 倒装(Inversion)

**正常语序倒过来,产生强调效果。**

#### 完全倒装(整个谓语提前):

```
Here / There / Now / Then + 动词 + 主语
```

> **Here comes** the bus.
> **There goes** my chance.

#### 部分倒装(助动词提前):

发生在**否定词 / 限制词置首**时。

| 触发词 | 例 |
|--------|-----|
| Never / Seldom / Rarely | **Never have I** seen such beauty. |
| Hardly ... when / No sooner ... than | **Hardly had I** arrived when she left. |
| Not only ... but also | **Not only is** he smart, **but** he **is** also kind. |
| Only + 状语 | **Only then did I** understand. |
| So + 形容词 ... that | **So beautiful was** the view that ... |

### 2️⃣ 强调句(Cleft Sentence)

**用 It is / was ... that ... 强调某成分。**

```
It is/was + 被强调部分 + that + 其余
```

> 原句:Tom bought a car yesterday.
> 强调 Tom:**It was Tom that / who bought a car yesterday.**
> 强调 a car:**It was a car that Tom bought yesterday.**
> 强调时间:**It was yesterday that Tom bought a car.**

⚠️ 强调主语用 that 或 who;其他用 that

#### 强调谓语:do / does / did + 原形

> I **do** love you.(我真的爱你)
> She **did** call me.(她确实打了电话)

### 3️⃣ 省略(Ellipsis)

**为避免重复,省去已知信息。**

> I can do it, and **you can (do it) too**.
> She told me to leave, so **I did (leave)**.
> **(I'm) Glad to meet you.**(口语省主)
> **(If) Necessary**, call me.(条件状语省略)

### 4️⃣ 独立主格(Absolute Construction)

**逻辑主语 ≠ 主句主语 时,显式带主语 + 分词。**

```
名词 / 代词 + 分词 + ...,主句
```

> **The weather being fine**, we went hiking.
> **All the work done**, we went home.
> **Weather permitting**, the picnic will go ahead.

📌 详见 [英语非谓语动词完全指南.md](英语非谓语动词完全指南.md)。

### 5️⃣ 同位语(Apposition)

**两个名词成分指同一事物,用逗号隔开。**

> Beijing, **the capital of China**, is huge.
> My friend Tom, **a doctor**, called me.
> The idea **that he lied** shocked me.(同位语从句)

### 6️⃣ 插入语(Parenthetical)

**句中插入解释 / 评论的成分,常用逗号或破折号隔开。**

> The result, **as you can see**, is positive.
> He is, **to be honest**, a fool.
> She — **my best friend** — moved abroad.

### 7️⃣ 形式主语 / 宾语(Anticipatory it)

**用 it 占位,真正主 / 宾后置。**

#### 形式主语:

> **It** is important **to learn English**.
> = To learn English is important.

#### 形式宾语:

> I find **it** hard **to wake up early**.
> = I find to wake up early hard.(不地道,所以用 it)

## 八、一句话拆解练习

用一个例子贯穿所有层次:

```
The intelligent student, who studies hard every day,
considered the difficult problem easy to solve.
```

### Level 1:词性(每个词的"身份")

| 词 | 词性 |
|----|------|
| The | 冠词 |
| intelligent | 形容词 |
| student | 名词 |
| who | 关系代词 |
| studies | 动词 |
| hard | 副词 |
| every day | 名词词组(状语用) |
| considered | 动词 |
| the | 冠词 |
| difficult | 形容词 |
| problem | 名词 |
| easy | 形容词 |
| to solve | 不定式 |

### Level 2:句子成分(每个词的"角色")

```
[The intelligent student]    = 主语(主)
   ├── The = 定语(冠词作限定)
   ├── intelligent = 定语(形容词修饰)
   └── student = 主语核心

[who studies hard every day] = 定语从句(修饰 student)

[considered]                  = 谓语动词

[the difficult problem]       = 宾语(直接)
   └── difficult = 定语

[easy]                        = 宾语补足语(形容词描述 problem)

[to solve]                    = 状语 / 后置定语(不定式修饰 easy)
```

### Level 3:基本句型

```
S + V + O + C
主 + 谓 + 宾 + 宾补
(第五句型)
```

### Level 4:句子结构

```
复合句(主句 + 一个定语从句)
```

### Level 5:语气

```
陈述句
```

### Level 6:特殊结构

```
含定语从句(who studies hard every day)
不定式 to solve 作 easy 的后置补充
形容词 easy 作宾补
```
