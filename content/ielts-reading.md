## 一、Reading 整体认知

### 1️⃣ 考试结构

| 篇章 | 长度 | 难度 | 题数 |
|------|------|------|------|
| Passage 1 | ~900 字 | ★★ 较易 | 13-14 题 |
| Passage 2 | ~900 字 | ★★★ 中 | 13-14 题 |
| Passage 3 | ~900 字 | ★★★★ 难(学术) | 13-14 题 |

**总计:** 60 分钟 / 40 题

### 2️⃣ 评分换算

| 答对 | Band |
|------|------|
| 39-40 | 9.0 |
| 37-38 | 8.5 |
| 35-36 | 8.0 |
| 33-34 | 7.5 |
| 30-32 | 7.0 |
| 27-29 | 6.5 ⭐ |
| 23-26 | 6.0 |
| 19-22 | 5.5 |

📌 **目标 6.5 → 答对 27-29 题。** 错 11-13 题可接受。

### 3️⃣ 每篇时间分配

```
Passage 1:15 min(简单,要尽量快)
Passage 2:18 min
Passage 3:20 min
检查 + 涂卡:5 min(雅思 Reading 没有额外誊写时间!)

⚠️ 题号 Passage 1-3 共用一份答题卡,要直接写最终答案!
```

### 4️⃣ 核心心法

```
1. 先看题再读文章,不要先把全文读完
2. 同义替换是常态,关键词不会原词出现
3. 答案在文章中的顺序 = 题目顺序(大部分题型)
4. T/F/NG 和 Yes/No/NG 是两种不同题,别弄混
5. 一题超过 2 分钟就跳过,先做后面题
```

## 二、11 大题型深度解析

### 📝 题型 1:多项选择(Multiple Choice)

**特点:** A/B/C/D 四选一,有时是 A-G 多选

**策略:**

```
1. 划出题干关键词
2. 在文章中扫读对应段落
3. 用排除法
4. 注意"近似选项"陷阱:语言相似但意思相反 / 范围不同
```

**陷阱例:**
> 题目选项 A:"Most scientists agree that..."
> 文章原文:"A few scientists have argued that..."
> ❌ "Most" ≠ "A few"

### 📝 题型 2:True / False / Not Given

**详见第三节,这是雅思最易丢分题型!**

### 📝 题型 3:Yes / No / Not Given

**与 T/F/NG 的区别:**

| 题型 | 判断对象 |
|------|---------|
| **T/F/NG** | 客观事实(facts) |
| **Y/N/NG** | 作者观点(opinions / claims) |

📌 Y/N/NG 出现在评论 / 议论文中,问的是**作者怎么想**。

### 📝 题型 4:Heading Match(段落匹配标题)⭐

**特点:** 给一组标题(I-X 之类),把每个段落匹配到一个标题

**详见第四节。**

### 📝 题型 5:Information Match(段落信息匹配)

**特点:** 给一些"陈述",问每个陈述出现在哪一段(A-H)

**关键区别 vs Heading:**
- Heading = 段落主旨
- Info Match = 段落细节

**策略:**

```
1. 先读题目陈述,划关键词
2. 扫读每段开头 + 结尾(主旨在这里)
3. 注意:同一段可能有多个陈述
4. 同一陈述也可能不出现 → 做不出来不要硬选
```

### 📝 题型 6:Sentence Completion(句子填空)

**特点:** 给半截句子,要求从文章中找词补全

**策略:**

```
1. 看清字数限制(NO MORE THAN TWO/THREE WORDS)
2. 答案必须是文章原词,不能改写
3. 用语法判断:空格前后是什么词性 → 答案就是什么词性
```

### 📝 题型 7:Summary Completion(摘要填空)

**详见第五节。**

### 📝 题型 8:Diagram / Flow-Chart Labelling(图表标注)

**特点:** 给一张图(机械结构 / 流程图),要求标注

**策略:**

```
1. 先看图,理解结构
2. 在文章中找对应的描述段落
3. 答案多为名词
```

### 📝 题型 9:Matching Names / Theories(人名 / 理论配对)

**特点:** 把人名 / 理论与观点匹配

**策略:**

```
1. 先在文章中圈出所有人名
2. 阅读每个人附近的内容,概括其观点
3. 与题目陈述对比
4. 注意"否定关系":A 反对 B 的观点
```

### 📝 题型 10:Short Answer(简答)

**特点:** 简短回答问题(NO MORE THAN THREE WORDS)

**策略:**

```
1. 用问题词(What/Where/When/Who/Why/How)定位
2. 答案是文章中的原词
3. 严格控制字数
```

### 📝 题型 11:Matching Features(特征配对)

**特点:** 把特征 / 特点配对到不同事物 / 时期 / 国家

**策略:**

```
1. 先标注文章中提到的所有"事物 / 时期 / 国家"
2. 在每个对象附近找特征描述
3. 配对
```

## 三、True / False / Not Given 专项 ⭐ 最高频陷阱

### 1️⃣ 三个判断的本质

| 判断 | 含义 | 关键 |
|------|------|------|
| **TRUE** | 题目陈述与文章信息**完全一致** | 同义替换 |
| **FALSE** | 题目陈述与文章信息**直接矛盾** | 反义 / 不同数据 |
| **NOT GIVEN** | 文章**没提到 / 没说清楚** | 信息不完整 |

### 2️⃣ 判断决策树

```
Step 1:在文章中找到对应段落(用关键词定位)

Step 2:对比题目和文章
  ├── 完全一致(同义替换 OK)→ TRUE
  ├── 直接矛盾(数据 / 时间 / 程度反了)→ FALSE
  └── 文章没提 / 提了但没说够 → NOT GIVEN
```

### 3️⃣ TRUE 的判断要点

**TRUE = 题目陈述的所有要素都在文章中得到确认**

> 文章:"Researchers found that regular exercise improves cardiovascular
> health in adults over 50."

> 题目:"Exercise has positive effects on heart health in older people."

> ✅ TRUE
> (regular exercise = exercise; cardiovascular health = heart health;
> adults over 50 = older people。所有要素一致。)

### 4️⃣ FALSE 的判断要点

**FALSE = 题目与文章在关键点上明确矛盾**

| 文章原文 | 题目陈述 | 判断 |
|---------|---------|------|
| 增加了 30% | 减少了 30% | FALSE(数据相反) |
| 大多数科学家认为 | 少数科学家认为 | FALSE(范围相反) |
| 自 2010 年开始 | 自 2000 年开始 | FALSE(时间不同) |
| 有效的 | 无效的 | FALSE(程度相反) |
| 仅在 X 国 | 在所有国家 | FALSE(范围不同) |

### 5️⃣ NOT GIVEN 的判断要点

**NOT GIVEN = 文章没说 / 信息不完整 / 无法判断**

#### NG 三种典型情况:

**① 文章没提到**

> 文章:"The study examined 500 participants in the UK."
> 题目:"The study had a budget of over £1 million."
> → NOT GIVEN(预算根本没提)

**② 文章提了一部分,但题目多出"想象的内容"**

> 文章:"The new drug reduced symptoms in 60% of patients."
> 题目:"The new drug is the most effective treatment available."
> → NOT GIVEN(文章只说有效,没说"最有效")

**③ 范围不一致**

> 文章:"Children under 10 enjoyed the game."
> 题目:"All children enjoyed the game."
> → NOT GIVEN(under 10 ≠ all children)

### 6️⃣ T/F/NG 黄金口诀 ⭐

```
T:"完全对"→ 信息一致(同义改写)
F:"反着说"→ 数据 / 程度 / 方向相反
NG:"我猜的"→ 题目说了文章没说的,或加了想象内容
```

### 7️⃣ T/F/NG 常见陷阱关键词

| 陷阱词 | 类型 | 例 |
|-------|------|-----|
| **all / every / always** | 极端绝对化 | 文章常用"some / often",题目偷换为 all → 多为 FALSE |
| **only / merely / solely** | 限定唯一 | 偷换排除性 |
| **most / majority** | 程度词 | 文章是 some / a few,题目偷换为 most → FALSE |
| **the same / similar / different** | 比较 | 容易制造比较关系陷阱 |
| **first / second / always** | 排序 | 偷换顺序 |
| **because / due to / leads to** | 因果 | 文章只说现象,题目硬加因果 → 多为 NG |

### 8️⃣ T/F/NG 实战练习

#### 例 1
> 文章:"Coffee consumption has risen in Asia by 20% over the past decade."
> 题目:"More people in Asia drink coffee than in Europe."
> 答案:**NOT GIVEN**(没拿 Europe 比较)

#### 例 2
> 文章:"The architect designed the building in 1925, although it
> wasn't completed until 1932."
> 题目:"The building was finished in 1925."
> 答案:**FALSE**(完成时间是 1932,不是 1925)

#### 例 3
> 文章:"Most studies indicate that exposure to nature reduces stress."
> 题目:"All studies have found that nature reduces stress."
> 答案:**FALSE**(most ≠ all,但 most 已经接近 majority,所以这里
> 是 false,因为题目把"most"偷换为"all")
> ⚠️ 但若题目说 "Some studies suggest..." → TRUE

📌 **一句话总结:** TRUE 是"同义改写正确",FALSE 是"明确反对",NG 是"文章没说够"。

## 四、Heading Match 专项

### 1️⃣ 核心原则

**Heading = 段落"主旨",不是"细节"**

很多考生失分原因:**抓段落里的具体例子,而不是中心思想**。

### 2️⃣ 标准解题步骤 ⭐

```
Step 1:先读所有 Heading 选项(I-X)
        - 划出每个 Heading 的关键词
        - 找出"近似但不同"的 heading
        - 注意 examples / cases / overview 等关键词

Step 2:逐段读
        - 看段首句(Topic sentence)
        - 看段尾句(常有总结)
        - 中间快速浏览支撑细节

Step 3:匹配
        - 找最贴合段落"主旨"的 heading
        - 划掉已用的 heading(每个只用一次)

Step 4:难题最后做
        - 先做能确定的
        - 再用排除法解决犹豫的
```

### 3️⃣ Heading 题陷阱

#### 陷阱 1:细节诱惑

> 段落主要讲"环境保护的政策",但提到"日本曾出过一项法律"
>
> ❌ 错选 "Environmental policies in Japan"
> ✅ 正确 "Government measures to address pollution"

📌 **关键:** 看段落主要讲什么,不要被一个细节带偏。

#### 陷阱 2:相似 Heading

题目常给 2-3 个意思相似的 Heading,只有一个最准确。

| Heading 选项 | 关键差异 |
|------------|---------|
| The history of X | 强调"过去到现在的发展" |
| The origin of X | 强调"起源" |
| The impact of X | 强调"影响" |

### 4️⃣ Heading 题加速技巧

```
1. 通读全文前,先把 Heading 关键词圈出
2. 阅读段落时,一旦读到"明显匹配的 heading 关键词",立即标记
3. 短段落优先做(只有 3-4 句话,主旨明显)
4. 长段落最后做(信息多,难判断)
```

## 五、Summary Completion 专项

### 1️⃣ 两种 Summary

| 类型 | 特点 |
|------|------|
| **从文章原词中找词填空** | 答案必须是文章中出现的原词 |
| **从给定的词库中选词填空**(A-K 中选) | 答案是改写过的词,词库给出 |

### 2️⃣ 解题步骤

```
Step 1:读 Summary 全文
        - 不要看空格,先理解 summary 大意

Step 2:在文章中定位 Summary 对应段落
        - Summary 不一定按文章顺序

Step 3:逐空填写
        - 用语法判断词性(名词?动词?形容词?)
        - 用上下文判断意思
        - 同义替换思维:文章用 X 词,你要找哪个表达
```

### 3️⃣ Summary 关键技巧

#### ① 词性判断

```
"The researchers ____ a new method."
   主语 谓语?(动词)+ 名词

→ 答案应该是动词,过去式
→ 文章中找:developed / introduced / created
```

#### ② 同义替换识别

题目说 "researchers find",文章可能说 "scientists discover" → 这两个等价。

#### ③ 词库题(选词填空)注意

- 词库给的词常常**比文章原词更高级 / 更书面**
- 一定要严格按"语法 + 意思"双重匹配

## 六、扫读与定位技巧

### 🎯 三种阅读速度

| 速度 | 用途 | 何时用 |
|------|------|------|
| **Skimming(略读)** | 抓主旨 | 通读全文了解大意(可选) |
| **Scanning(扫读)** | 找具体信息 | 找关键词、数字、人名时 |
| **Detailed reading(精读)** | 理解细节 | 找到答案位置后,精读那 1-2 句 |

### 🎯 关键词定位 ⭐

#### 哪些是"好关键词"?

```
✅ 大写词(人名 / 地名 / 机构名 / 专有名词)
✅ 数字 / 年份
✅ 特殊术语(罕见词,不易换)
✅ 引号中的词
```

#### 哪些是"差关键词"?

```
❌ 普通名词(people / system / way)→ 文章中到处都是
❌ 普通动词(make / do / use)
❌ 题目中的虚词(the / and / of)
```

### 🎯 同义替换库 ⭐(必备)

| 题目 | 文章可能用 |
|------|-----------|
| problem | issue / challenge / difficulty |
| help | aid / assist / support / facilitate |
| change | alter / modify / shift / transform |
| important | significant / crucial / vital / essential |
| big | substantial / considerable / vast / enormous |
| small | minor / minimal / negligible |
| use | utilise / employ / apply |
| show | demonstrate / illustrate / reveal |
| think | believe / argue / claim / contend |
| many | numerous / a multitude of / countless |
| because | due to / as a result of / owing to |

### 🎯 文章结构识别

#### 议论文(常见于 Passage 3)

```
Para 1:Introduction(背景 + 论点)
Para 2-N:Arguments / Evidence
Para N+1:Counter-argument(可能)
最后一段:Conclusion(立场重申)
```

#### 描述文(常见于 Passage 1-2)

```
Para 1:Topic introduction
Para 2-N:Different aspects / phases / examples
最后一段:Summary / Implications
```

#### 历史 / 科普文

```
通常按时间顺序 → 注意年份和时期切换
```

## 七、时间管理与备考路径

### 🎯 60 分钟时间分配

| 任务 | 时间 | 注意 |
|------|------|------|
| Passage 1 | 15 min | 简单,争取多挤出 2-3 min |
| Passage 2 | 18 min | 中等 |
| Passage 3 | 20 min | 难,但用前面挤出的时间 |
| 涂卡 | 5 min | 雅思 Reading 没有额外誊写时间! |
| 缓冲 | 2 min | 检查难题 |

### ⚠️ 涂卡警告

```
雅思 Reading vs Listening:
- Listening:30 min 听 + 10 min 誊写
- Reading:60 min 包含全部!不能"再给 10 分钟誊写"
- 所以读题时直接在答题卡上写答案
```

### 🎯 6 周提分计划

#### Week 1-2:诊断 + 题型熟悉

```
- 做剑 17 Test 1(完整 60 min,记录原始分)
- 分析错题:
  - 是哪种题型最弱?(T/F/NG?Heading?)
  - 是单词不认识?(词汇问题)
  - 是定位失误?(扫读问题)
- 每天做 1 篇 Passage(不限时,质量优先)
```

#### Week 3-4:题型专项

```
Day 1-3:T/F/NG 专项(一次做 30+ 道题,找规律)
Day 4-7:Heading 专项
Day 8-10:Summary / Sentence Completion
Day 11-14:Multiple Choice + Matching
```

#### Week 5:全套限时

```
- 每天 1 套完整 Reading(60 min 严格限时)
- 涂卡训练(直接涂)
- 错题精读:每篇错题 10+ 道的文章,精读重做
```

#### Week 6:漏洞修补

```
- 集中刷弱项题型
- 真题三刷:重做剑 17/18,看是否还错
- 模拟考试节奏(全套 60 min,卡时间)
```

### 🎯 词汇拓展(对你来说最不需要补)

雅思 Reading 词汇 ≈ 学术 8000 词 + 同义替换库

**对一个十年读 arXiv 的人:**
- Passage 3 学术词汇你大概率没问题
- 真正要补的是"题目同义替换"(本指南第六节的库)

📌 **如果还需要补词汇,推荐:**
- 《雅思核心词汇 21 天突破》(刘洪波)
- Quizlet 上搜 "IELTS reading paraphrase"

### 🎯 资源推荐

| 资源 | 价格 | 用途 |
|------|------|------|
| **剑桥雅思真题集 17/18/19** | ¥120 | 必备真题 |
| **何琼《雅思阅读真经总纲》** | ¥40 | 解题方法论 |
| **The Economist / Scientific American** | 网上免费 | 学术阅读输入 |
