## 一、Listening 整体认知

### 1️⃣ 考试结构

| Section | 场景 | 题型 | 难度 | 题数 |
|---------|------|------|------|------|
| **Part 1** | 日常对话(2 人,如咨询、报名、租房) | 表格填空为主 | ★ | 10 |
| **Part 2** | 独白(1 人,如导览、介绍设施) | 地图、配对、选择 | ★★ | 10 |
| **Part 3** | 学术对话(2-4 人,如导师讨论、小组作业) | 选择、配对、流程 | ★★★ | 10 |
| **Part 4** | 学术讲座(1 人独白,如生物 / 历史 / 科技) | 笔记填空为主 | ★★★★ | 10 |

📌 **难度递增**,Part 1 最简单 → Part 4 最难

### 2️⃣ 评分换算

| 答对 | Band |
|------|------|
| 39-40 | 9.0 |
| 37-38 | 8.5 |
| 35-36 | 8.0 |
| 32-34 | 7.5 |
| 30-31 | 7.0 |
| 26-29 | 6.5 ⭐ |
| 23-25 | 6.0 |
| 18-22 | 5.5 |

📌 **目标 6.5 → 答对 26-29 题。** 可以错 11-14 题。

### 3️⃣ 核心心法

```
1. 不要纠结一题:听漏了立刻放下,听下一题
2. 边听边读题:在听上一题时已浏览下面 2-3 题
3. 关键词预测:听之前判断空格"是名词?数字?地名?"
4. 别完全依赖关键词:同义替换是常态
5. 检查拼写:大小写、单复数、连字符
```

## 二、4 大 Section 特点与策略

### 🎯 Part 1:日常对话(咨询 / 报名 / 服务)

#### 高频场景
- 报名课程 / 旅行 / 健身房
- 租房 / 找工作 / 银行业务
- 投诉 / 失物招领 / 导游咨询

#### 题型分布
- **80% 填空题(表格)**
- 偶尔有选择题

#### 必考考点
| 考点 | 难度 |
|------|------|
| 数字(电话、日期、价格、距离) | ★★ |
| 地名 / 街道名 / 人名拼写 | ★★★ |
| 时间(am/pm 切换) | ★★ |
| 单位(kg / km / £ / $) | ★ |

#### 必备策略

```
1. 先读表格,圈出空格 + 提示词类型
2. 听到关键词时,准备好下笔
3. 注意"修正"陷阱:说话人会改答案
   ⚠️ "Actually, no, it's 25, not 35."
   ⚠️ "Sorry, I meant Tuesday, not Monday."
4. 答案一律用题目要求的字数
   "NO MORE THAN TWO WORDS" → 1-2 个词
```

### 🎯 Part 2:独白(导览 / 介绍)

#### 高频场景
- 博物馆 / 公园 / 度假村导览
- 社区设施介绍
- 活动安排介绍

#### 题型分布
- **地图题**(必有,雅思考生最怕)
- **配对题**(把建筑 / 设施配对)
- 选择题

#### 地图题 ⭐ 重点

**必备方位词:**

| 方位 | 表达 |
|------|------|
| 在...的北边 | (to the) north of / (just) above |
| 在...的南边 | (to the) south of / (just) below |
| 在...的东边 | (to the) east of / right of |
| 在...的西边 | (to the) west of / left of |
| 在...对面 | opposite / across from |
| 在...旁边 | next to / beside / adjacent to |
| 在...之间 | between A and B |
| 在...角落 | in the corner / at the end of |
| 沿着...走 | along / down the path |
| 直走然后右转 | go straight, then turn right |
| 第二个右转 | the second turning on the right |
| 在尽头 | at the end (of) / at the far end |

**地图题策略:**

```
1. 听之前先标记起点(starting point / where we are now)
2. 听之前快速读所有选项(A-H 之类)
3. 边听边在地图上画移动路径
4. 注意"否定提示":
   "It's NOT next to the cafe, but..."
   "Originally we planned to put it here, but actually..."
```

### 🎯 Part 3:学术对话(2-4 人讨论)

#### 高频场景
- 学生与导师讨论作业 / 论文
- 小组讨论项目
- 课程注册 / 选课

#### 题型分布
- **选择题**(多)
- **配对题**(把人物与观点配对)
- 流程题

#### 必备策略

```
1. 注意人物身份:tutor / student / partner
2. 注意"同意 / 不同意":
   "I agree" / "I'm not so sure" / "Actually..."
3. 注意"建议接受 / 拒绝":
   "Let's go with that" / "I don't think that'll work"
4. 选择题要听完整,别抢答(选项常含"陷阱关键词")
```

#### Part 3 经典陷阱:

> Question: What does the student decide to focus on?
> A) Climate change
> B) Marine biology
> C) Renewable energy

> 录音:"I was thinking of climate change, but my tutor suggested
> looking at marine biology — actually, after considering the data
> availability, I'll focus on renewable energy instead."

> ✅ 答案:**C** (说了 3 个,关键是最后决定)

### 🎯 Part 4:学术讲座(1 人独白)

#### 高频话题
- 生物 / 生态 / 环境
- 历史 / 考古 / 文化
- 科学发现 / 新技术
- 教育 / 心理学

#### 题型分布
- **80% 填空题(笔记)**

#### 必备策略

```
1. 这是难度最高的部分,但题型最套路化
2. 必有"信号词"标记答案位置:
   "First/Next/Then/Finally"
   "The most important factor is..."
   "Researchers found that..."
3. 答案多为名词(60%) / 名词短语
4. 注意"听到的词" ≠ "要填的词"
   常常是同义改写
```

#### Part 4 信号词大全

| 信号 | 表达 |
|------|------|
| 列举 | Firstly / Secondly / Furthermore / In addition |
| 因果 | This led to / Because of / As a result / Consequently |
| 对比 | However / In contrast / On the other hand / Whereas |
| 强调 | The key point is / Most importantly / Crucially |
| 举例 | For example / Take X for instance / Such as |
| 总结 | To summarise / In conclusion / Overall |

## 三、10 大题型攻略

### 📝 题型 1:表格填空(Form / Note Completion)

**特点:** 给一个表格,留空位让你填关键信息(姓名、地址、电话等)

**策略:**

```
1. 看清字数限制(NO MORE THAN ONE/TWO/THREE WORDS)
2. 通过空格上下文判断"应该填什么类型的词"
   - 时间 → 数字 / 月份
   - 价格 → £ / $ + 数字
   - 名字 → 大写
3. 预读时圈出关键词
```

**陷阱:**
- 答案改口("Actually, change that to...")
- 拼写陷阱(地名、人名)

### 📝 题型 2:笔记填空(Note Completion)

**特点:** Part 4 主要题型,讲座大纲式笔记

**策略:**

```
1. 找笔记中的"标题 / 子标题"作为听力路标
2. 预测每个空格的词性 / 类别
3. 注意复数 -s / 动词 -ing 形式
```

### 📝 题型 3:句子填空(Sentence Completion)

**特点:** 完整句子留空

**策略:**

```
1. 从句子语法判断"必须填什么类型"
   - "is a ____" → 名词
   - "to ____" → 动词原形
   - "very ____" → 形容词
2. 答案常是同义替换,听完整句
```

### 📝 题型 4:简答题(Short-Answer Questions)

**特点:** 问句,要求简短回答(通常 NO MORE THAN THREE WORDS)

**策略:**

```
1. 仔细看问题词:What / Where / When / Who / How many / Why
2. 答案就在问题之后听到的内容里
3. 严格控制字数
```

### 📝 题型 5:单选题(Multiple Choice)

**特点:** A/B/C 三选一(偶尔 A-E 五选三)

**策略:**

```
1. 预读时划出三个选项的关键词差异
2. 听录音时,三个选项的内容可能都被提到
   ⚠️ 别听到一个就选,要听完整句!
3. 注意"否定 / 转折"信号
   "Although... I prefer..."
```

**经典陷阱(Part 3 必考):**
> 录音说 A,但接着说 "actually I think B is better" → 答案 B

### 📝 题型 6:配对题(Matching)

**特点:** 把选项与答案配对(如人 vs 观点 / 设施 vs 位置)

**策略:**

```
1. 预读所有选项(常 A-G)
2. 划出每个选项的关键词
3. 听到一个就划掉(避免重复使用 / 错过)
4. 注意:有时选项数量 > 题目数,有"干扰项"
```

### 📝 题型 7:地图题 ⭐(Plan / Map Labelling)

**特点:** 给一张地图,要求把字母 A-H 配到题目位置

**策略:**

```
1. 预读地图:
   - 找到起点(starting point / "where we are now")
   - 标记主要参照物(building / road / lake)
   - 把方位词写在地图上(N/S/E/W)
2. 边听边沿路径走
3. 注意"路径调整"
   "Actually, you'll need to take the path that goes around the lake."
```

**地图题救命提醒:**
- 有些方向是相对的("on your left as you enter")
- 别把地图反过来读!以你站立的方向看

### 📝 题型 8:流程图填空(Flow-Chart)

**特点:** 类似 Task 1 流程图,但听力中很少见

**策略:**

```
1. 看流程图箭头确定顺序
2. 听信号词:First / Next / After that / Finally
3. 答案常是动词或名词
```

### 📝 题型 9:分类题(Classification)

**特点:** 把多个项目分到不同类别(如 A 城市 / B 城市 / 两个都有)

**策略:**

```
1. 看清类别标签
2. 边听边对应,可在题目旁标 A/B/C
```

### 📝 题型 10:选词填空(Multiple-choice with Multiple Answers)

**特点:** 从 7-8 个选项中选 2-3 个

**策略:**

```
1. 答案不分顺序
2. 选项可能多次提及但不一定都正确
3. 听完整段再做决定
```

## 四、听力陷阱大全

### ⚠️ 陷阱 1:同义替换(最高频!)

**录音说一种说法,题目用另一种说法**

| 录音听到 | 题目可能写 |
|---------|-----------|
| young people | the youth / the younger generation |
| good for health | beneficial / promotes well-being |
| save money | cut costs / reduce expenses |
| difficult | challenging / hard / tricky |
| started | began / commenced / launched |

📌 **解法:** 听**意思**,不要只听单词。

### ⚠️ 陷阱 2:答案改口

```
"My number is 098 543 — wait, sorry, 098 5 4 5."
"It's on Mill Street — actually, sorry, Mill Avenue."
"Originally I was going to study biology, but I changed to chemistry."
```

📌 **关键词:** "actually / sorry / wait / no, I mean / let me correct that"
**永远以最后说的为准!**

### ⚠️ 陷阱 3:数字混淆

| 易混 | 区别发音 |
|------|---------|
| 13 / 30 | thir-**TEEN** / **THIR**-ty |
| 14 / 40 | four-**TEEN** / **FOUR**-ty |
| 15 / 50 | fif-**TEEN** / **FIF**-ty |
| 16 / 60 | six-**TEEN** / **SIX**-ty |

📌 **规律:** -teen 重音在后,-ty 重音在前

### ⚠️ 陷阱 4:近音词

| 易混 | 用法 |
|------|------|
| accept / except | 接受 / 除了 |
| affect / effect | 影响(动) / 效果(名) |
| their / there | 他们的 / 那里 |
| weather / whether | 天气 / 是否 |
| desert / dessert | 沙漠 / 甜点 |
| principal / principle | 校长 / 原则 |

### ⚠️ 陷阱 5:多重信息干扰

录音提到多个数字 / 名字 / 地点,只有一个是答案。

> "We have three branches — one in Manchester, one in Leeds, and our
> head office in Birmingham. The training will be held at Birmingham."

> Question: Where is the training? **答案:Birmingham**(其他都是干扰)

### ⚠️ 陷阱 6:连读 / 弱读

英澳口音中:

| 现象 | 例 |
|------|-----|
| 失爆 | "next time" → "nex'time" |
| 连读 | "an apple" → "a-napple" |
| 弱读 | "for me" → "f'me" |
| t 浊化(美) | "water" → "wader" |

📌 **解法:每天听 BBC + 美剧/英剧,15 分钟 / 天养语感**

## 五、拼写与数字专项

### 🎯 字母听写练习(必练!)

中国考生听力丢分,**30% 是字母拼写错!**

#### 易混字母

| 字母 | 易混 | 区别 |
|------|------|------|
| A | E / I / 8 | /eɪ/ vs /iː/ vs /aɪ/ |
| B | P / D / V | /biː/ vs /piː/ |
| G | J | /dʒiː/ vs /dʒeɪ/ |
| M | N | 唇音 vs 鼻音 |
| Q | U | /kjuː/ |
| W | double-U | 注意三音节 |
| Y | I / E | /waɪ/ |

📌 **练习方法:**
- 每天 5 分钟,让朋友 / app 随机读 20 个字母,默写
- 听 BBC 时遇到拼写就跟着默写

### 🎯 高频地名 / 街名拼写(必背)

| 类型 | 例 |
|------|-----|
| 街道后缀 | Street / Road / Avenue / Lane / Drive / Crescent |
| 英国地名 | Manchester / Birmingham / Edinburgh / Cambridge |
| 美国地名 | California / Massachusetts / Pennsylvania |
| 易错 | Heathrow / Loughborough / Worcestershire |

### 🎯 数字读法

#### 电话号码
- "0" 读作 "oh" 或 "zero"
- 双数字 "44" 读作 "double four"
- 三个相同 "555" 读作 "triple five"
- 长串数字按 3-4 个一组分组

#### 日期
- 美式:May 10th, 2026 → 5/10/2026
- 英式:10th May 2026 → 10/5/2026
- ⚠️ 雅思以**英式为主**

#### 货币
- £ → "pounds"
- $ → "dollars"
- € → "euros"
- ¥ → "yuan / yen"

#### 大数字
- 1,000 = a thousand
- 10,000 = ten thousand
- 100,000 = a hundred thousand
- 1,000,000 = a million
- 1,000,000,000 = a billion(美式 / 英式都用)

#### 小数
- 0.5 → "zero point five" / "nought point five"(英)
- 2.45 → "two point four five"

#### 分数
- 1/2 → "one half / a half"
- 1/3 → "one third / a third"
- 3/4 → "three quarters"

### 🎯 度量单位

| 单位 | 读 |
|------|-----|
| km | kilometre |
| m | metre |
| cm | centimetre |
| kg | kilogram |
| g | gram |
| °C | degrees Celsius |
| % | per cent |

## 六、英澳口音应对

### 🎯 雅思听力 4 大口音分布

| 口音 | 占比 | 特点 |
|------|------|------|
| 英国(BBC English) | 40% | RP / 标准发音 |
| 澳大利亚 | 30% | 元音偏 |
| 美国 | 20% | t 浊化 / r 卷舌 |
| 加拿大 / 新西兰 / 印度 | 10% | 偶尔出现 |

### 🎯 英国口音特点

| 特点 | 例 |
|------|-----|
| 不卷舌 | "car" → /kɑː/(无 r) |
| /æ/ → /ɑː/ | "dance" → /dɑːns/ |
| t 清晰 | "water" → /ˈwɔːtə/ |
| 弱读 your | "your" → /jə/ |

### 🎯 澳大利亚口音特点

| 特点 | 例 |
|------|-----|
| /eɪ/ → /aɪ/ | "today" 像 "to-die" |
| /aɪ/ → /ɔɪ/ | "high" 像 "hoy" |
| 单词收尾上扬 | 听起来像问句 |
| 短化 | "afternoon" → "arvo" |

📌 **澳音应对:** 别被语调骗,内容才是关键。多听 ABC News(澳)的播报。

## 七、备考与提分路径

### 🎯 6 周提分计划

#### Week 1-2:基础诊断 + 题型熟悉

```
- 做剑 17 Test 1 全部 4 个 Part(完整模考,记录原始分)
- 分析错题:
  - 是听不懂?(基础问题)
  - 是没听到?(注意力问题)
  - 是听到但拼错?(拼写问题)
  - 是误解题目?(题型问题)
- 每天 BBC 6 Minute English × 1 集(精听)
```

#### Week 3-4:题型专项

```
- Day 1-3:地图题专项(剑 17/18/19 所有 Part 2 地图题)
- Day 4-7:Part 3 配对题专项
- Day 8-10:Part 4 笔记填空精听
- Day 11-14:数字 + 拼写专项
```

#### Week 5:全套限时

```
- 每天 1 套完整 Listening(30 min + 10 min 誊写)
- 严格按真实考试条件
- 错题做"二刷":听不出来的句子精听 5 遍
```

#### Week 6:漏洞修补

```
- 整理错题本,找规律
- 是哪种题型 / 哪种话题最弱?
- 集中突破 + 真题再刷
```

### 🎯 精听方法 ⭐(快速提分核心)

```
Step 1:盲听一遍,做题
Step 2:对答案,标记错题
Step 3:看着原文,听一遍(找出"听漏"的位置)
Step 4:不看原文,跟读 2-3 遍
Step 5:盲听到 100% 听懂为止
```

**精听一篇文章 ≈ 泛听 10 篇文章。**
