## 一、句子的基本成分

| 成分 | 作用 | 例(I gave him a book happily yesterday.) |
|------|------|------|
| **主语 S** | 谁 / 什么 | **I** |
| **谓语 V** | 做了什么 | **gave** |
| **宾语 O** | 谁 / 什么(被动作影响的对象) | **a book**(直接宾语)、**him**(间接宾语) |
| **表语 P** | 描述主语(在系动词后) | She is **happy**. → happy 是表语 |
| **定语** | 修饰名词 | a **red** apple |
| **状语** | 修饰动词/句子 | I work **hard** / **every day** |
| **补语 C** | 补充说明宾语 | We made him **captain**. → captain 是宾补 |

## 二、五大基本句型

### 1️⃣ S + V(主语 + 谓语)

最简单的句型,**不及物动词**(动作不需要对象)。

> **The baby cried.**(婴儿哭了)
> **Birds fly.**(鸟飞)
> **He arrived.**(他到了)
> **Time flies.**(时间飞逝)

📌 **常见不及物动词:** come, go, sleep, run, walk, fly, sit, stand, work, rise, fall, happen, exist, live, die

### 2️⃣ S + V + O(主语 + 谓语 + 宾语)⭐ 最常用

**及物动词**(动作需要对象)。

> **I love English.**(我爱英语)
> **She wrote a book.**(她写了一本书)
> **They built a house.**(他们建了房子)

📌 **常见及物动词:** love, like, want, need, see, hear, watch, write, read, build, make, do, have, learn

### 3️⃣ S + V + P(主语 + 系动词 + 表语)

**系动词**后接**表语**(描述主语的状态/特征)。

| 系动词 | 含义 | 例 |
|--------|------|-----|
| **be** | 是 | He **is** a teacher. |
| **become** | 变成 | She **became** famous. |
| **get** | 变得 | It's **getting** cold. |
| **turn** | 变成 | Leaves **turn** yellow. |
| **seem / appear** | 似乎 | He **seems** tired. |
| **look** | 看起来 | You **look** great. |
| **sound** | 听起来 | That **sounds** good. |
| **feel** | 感觉 | I **feel** sick. |
| **smell** | 闻起来 | It **smells** delicious. |
| **taste** | 尝起来 | This **tastes** sweet. |
| **stay / remain / keep** | 保持 | Please **stay** calm. |

⚠️ **关键:系动词后用形容词,不是副词!**
- ✅ The food smells **good**.
- ❌ The food smells **well**.

### 4️⃣ S + V + IO + DO(主语 + 谓语 + 间接宾语 + 直接宾语)

**双宾语**:常见于"给予"类动词。

```
S + V + 人 + 物
S + V + 物 + to / for + 人
```

> **I gave him a book.** = **I gave a book to him.**
> **She bought me a gift.** = **She bought a gift for me.**

📌 **常见双宾语动词:**
- 用 **to**:give, send, show, tell, lend, pass, teach, write, offer
- 用 **for**:buy, make, cook, find, get, save, build, choose

### 5️⃣ S + V + O + C(主语 + 谓语 + 宾语 + 宾补)

**宾语补足语**:补充说明宾语的状态/身份。

```
S + V + O + (名词/形容词/动词)做宾补
```

#### 宾补是名词

> They **elected him president**.(选他做主席)
> We **call her Mary**.

#### 宾补是形容词

> She **made me happy**.
> Coffee **keeps me awake**.

#### 宾补是动词原形(感官 / 使役动词)

| 动词 | 后跟 | 含义 |
|------|------|------|
| **make / let / have** sb **do** | 动词原形 | 让某人做 |
| **see / hear / watch / feel** sb **do** | 动词原形 | 看到/听到完整过程 |
| **see / hear / watch** sb **doing** | 现在分词 | 看到/听到正在进行 |

> She **made me cry**.(让我哭)
> I **let him go**.
> I **saw him cross** the street.(看到完整过程)
> I **saw him crossing** the street.(看到正在过)

#### 宾补是 to do(劝说类)

> She **asked me to leave**.
> I **want you to come**.
> They **expect us to win**.

📌 **常见动词:** want, ask, tell, expect, allow, advise, encourage, force, persuade, invite, order

⚠️ **特殊:help 两种都行**
> I helped him (to) finish.

## 三、there be 句型

**结构:** There + be + 主语 + 地点/时间

```
There is + 单数 / 不可数
There are + 复数
```

### 时态变化

| 时态 | 例 |
|------|-----|
| 现在 | **There is** a book on the table. |
| 过去 | **There was** a meeting yesterday. |
| 将来 | **There will be** a party. |
| 完成 | **There has been** a change. |
| 情态 | **There must be** a reason. |

### ⚠️ 常错点

#### 错误 1:主谓一致错误

❌ There **is** three apples.
✅ There **are** three apples.(数量看 be 后的名词)

❌ There **are** a book and two pens.
✅ There **is** a book and two pens.(就近原则,看最近的 a book)

#### 错误 2:把"有"翻译成 have

中文"桌上有本书"的"有"= **There is**,不是 have。

❌ The table **has** a book.
✅ **There is** a book on the table.

📌 **have**(拥有)用于具体所有者:
> **I have** a book.(我有一本书)
> **The room has** two windows.(描述特征,可以)

#### 错误 3:there be 和谓语动词

> **There is** a man **standing** at the door.(分词作后置定语)
> **There are** people **waiting** outside.

## 四、疑问句构造

### 1️⃣ 一般疑问句(yes / no 回答)

```
助动词 / be 动词 + 主语 + 其他

Do / Does / Did
Am / Is / Are / Was / Were
Have / Has / Had
Will / Would / Can / Could / Should / Must
```

| 句型 | 例 |
|------|-----|
| Do/Does + 原形 | **Do you** like coffee? |
| Did + 原形 | **Did she** call? |
| Be 动词 | **Are you** ready? |
| Have/Has + 过分 | **Have you** finished? |
| 情态动词 | **Can you** swim? |

### 2️⃣ 特殊疑问句(疑问词开头)

```
疑问词 + 一般疑问句

Where do you live?
What did you do?
Who is calling?
```

### 常用疑问词

| 词 | 问 |
|----|-----|
| **What** | 什么(物/事) |
| **Who / Whom** | 谁(主格 / 宾格) |
| **Whose** | 谁的 |
| **Which** | 哪一个 |
| **When** | 什么时候 |
| **Where** | 哪里 |
| **Why** | 为什么 |
| **How** | 怎么样 / 如何 |
| **How many / much** | 多少 |
| **How long / often / far** | 多久 / 多频繁 / 多远 |
| **How old** | 几岁 |
| **What time** | 几点 |
| **What kind of** | 什么种类的 |

### 3️⃣ 反义疑问句(...,对吧?)

**结构:** 陈述句(肯定)+ 反义部分(否定); 反之亦然。

> You are tired, **aren't you**?
> She doesn't drink, **does she**?
> He's been there, **hasn't he**?

⚠️ **特殊:**
- I am ..., **aren't I**?(惯用)
- 祈使句, **will you**?
- Let's ..., **shall we**?
- There is ..., **isn't there**?

### 4️⃣ 选择疑问句

**用 or 连接,不能 yes/no 回答。**

> **Do you want tea or coffee?**
> 答:Tea, please.(不是 yes / no)

## 五、否定句构造

```
1. be 动词 → 直接加 not
2. 助动词 → 助动词后加 not
3. 实义动词 → 加 do/does/did + not + 原形
4. 情态动词 → 情态后加 not
```

| 类型 | 例 |
|------|-----|
| be 否定 | She **is not / isn't** here. |
| 助动否定 | They **don't / doesn't / didn't** know. |
| 完成否定 | I **haven't** seen him. |
| 将来否定 | I **won't** go. |
| 情态否定 | You **can't / shouldn't / mustn't** do that. |

### 常用缩写

| 全 | 缩 |
|----|-----|
| is not | isn't |
| are not | aren't |
| was not | wasn't |
| were not | weren't |
| do not | don't |
| does not | doesn't |
| did not | didn't |
| have not | haven't |
| has not | hasn't |
| had not | hadn't |
| will not | **won't**(特殊) |
| would not | wouldn't |
| can not | **can't / cannot** |
| could not | couldn't |
| should not | shouldn't |
| must not | mustn't |

### 否定词

除了 not,这些词也表示否定:
- **no, never, nobody, nothing, nowhere, none, neither, nor**

> I have **no** money.
> He **never** lies.
> **Nobody** came.
> **Neither** of them is right.

⚠️ **双重否定 = 肯定**(英语规则,与中文不同!)
- ❌ I don't know nothing.(中式逻辑想表"什么都不知道")
- ✅ I **don't know anything**. / I **know nothing**.

## 六、雅思写作高分句型

### 1️⃣ 强调句型:It is ... that ...

> **It is** education **that** changes lives.(强调 education)
> **It was** in 2020 **that** the pandemic began.(强调时间)

### 2️⃣ 倒装句(高分稀缺技巧)⭐

**否定词置首,部分倒装:**

> **Not only** is education important, **but** it **is also** transformative.
> **Never** have I seen such beauty.
> **Hardly** had I arrived **when** the meeting started.
> **Only by working hard** can we succeed.

### 3️⃣ 强调对比

> **Whereas** A focuses on quantity, B emphasizes quality.
> **While** some prefer X, others believe Y.
> **Unlike** A, B is more flexible.

### 4️⃣ 因果句型

| 句型 | 例 |
|------|-----|
| 名词 + lead to + 名词 | Pollution **leads to** climate change. |
| 名词 + result in + 名词 | Stress **results in** illness. |
| ... due to / owing to + 名词 | The delay was **due to** weather. |
| ... thanks to + 名词 | **Thanks to** technology, we connect easily. |
| Such + 名词 + that ... | **Such** was the impact **that** ... |
| So + 形 + that ... | It was **so cold that** the lake froze. |

### 5️⃣ 让步句型

| 句型 | 例 |
|------|-----|
| Although / Though + 句子 | **Although** it rained, we went out. |
| Despite / In spite of + 名词 | **Despite** the rain, we went out. |
| 形容词 + as / though + 主 + be | **Difficult as** it is, we must try. |
| Even though / Even if | **Even though** I'm tired, I'll continue. |

### 6️⃣ 条件句型

| 类型 | 结构 | 例 |
|------|------|-----|
| 真实条件(0/1类) | If + 现在,will + 原形 | If it rains, I **will stay** home. |
| 不真实(2类) | If + 过去,would + 原形 | If I **were** you, I **would go**. |
| 不真实过去(3类) | If + had + 过分,would have + 过分 | If I **had known**, I **would have helped**. |

### 7️⃣ 雅思议论文常用模板

**引出观点:**
> It is widely believed that ...
> There is a common perception that ...
> Many people argue that ...

**表达自己看法:**
> From my perspective, ...
> In my opinion, ...
> I am convinced that ...

**举例:**
> A case in point is ...
> Take ... as an example.
> For instance, ...

**总结:**
> In conclusion, ...
> To sum up, ...
> All things considered, ...
