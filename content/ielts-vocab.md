## 一、核心心法:词汇升级思维

### ⚠️ 中国考生最大词汇问题

```
1. 反复用同一个简单词(important 出现 6 次)
2. 中式表达(very good / I think / many people)
3. 用词不准(serious 用来形容严重的雨)
4. 学了"高级词"但不会用(synergy / paradigm 强行塞入)
```

### ✅ 词汇升级三原则

```
原则 1:精准 > 高级
   "It's an interesting book" 比 "It's a captivating tome" 好
   ——用"装"的词反而扣分

原则 2:多样 > 重复
   同一个词 1 篇不要超过 3 次

原则 3:搭配 > 单词
   单独的高级词不重要,关键是 collocation(地道搭配)
   "make a decision" / "reach a conclusion" / "draw attention"
```

### 🎯 词汇升级 4 招

```
① 替换形容词:good → beneficial / favourable
② 替换动词:help → facilitate / assist
③ 名词化:解决问题 solve problems → find solutions
④ 用搭配:不只 important,要说 of paramount importance
```

## 四、口语高分短语

### 💎 表达观点

```
1. From my perspective, ...
2. The way I see it, ...
3. As far as I'm concerned, ...
4. Personally, I'd say ...
5. To my mind, ...
6. I'd argue that ...
7. I'm of the firm belief that ...
8. If you ask me, ...
9. Speaking from experience, ...
```

### 💎 表示同意 / 不同意

#### 同意
```
Absolutely. / Definitely.
I couldn't agree more.
That's spot on.
You've hit the nail on the head.
I'm with you on that.
```

#### 部分同意
```
I see your point, but...
You make a valid point, however...
There's some truth to that, although...
On balance, I'd say...
```

#### 不同意
```
I'd actually have to disagree.
I see it the other way around.
I'm not so sure about that.
That's a bit of an oversimplification.
I beg to differ.
```

### 💎 思考缓冲(避免冷场)

```
That's actually an interesting question.
Let me think about that for a moment.
That's not something I've thought about much, but...
Hmm, off the top of my head, I'd say...
I've never really considered that, but if I had to guess...
```

### 💎 举例

```
Take ... as a case in point.
A perfect example would be ...
Just look at ... — they ...
For instance / For example, ...
Imagine, for a moment, ...
Speaking of which, I remember ...
```

### 💎 加强语气

```
Without a doubt, ...
There's no question that ...
It goes without saying that ...
Needless to say, ...
By all means, ...
Quite frankly, ...
To be perfectly honest, ...
```

### 💎 转折 / 让步

```
Having said that, ...
That said, ...
Then again, ...
On the flip side, ...
At the same time, ...
However, it's also worth noting that ...
```

### 💎 总结

```
At the end of the day, ...
When all is said and done, ...
Long story short, ...
The bottom line is ...
All things considered, ...
On balance, ...
```

### 💎 万能"我感觉"短语

```
It struck me as ... (我感觉很...)
I find it ... (我觉得...)
What I love / hate about it is ...
What stands out for me is ...

```
